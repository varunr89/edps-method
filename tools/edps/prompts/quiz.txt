## Part A: Quick Recall (MCQ)

Create 3-4 multiple choice questions. For each question:
1. Specify the answer type: "one" (exactly one correct), "multiple" (2-3 correct), or "none" (none of the above is correct)
2. Include 4 options (A, B, C, D)
3. For "multiple" type: test which ASSUMPTIONS the argument depends on
4. For "none" type: test what would DISPROVE the argument (where none of the options actually would)
5. Make distractors plausible but distinguishable from correct answers
